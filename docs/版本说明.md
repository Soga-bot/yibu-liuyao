## v0.2.0（当前版本 · 2026-08-26 · commit `166a804`）

**定位**：体验层收官轮——P2-9 分享与深色完成 + 背景音乐接口预留。

**前置**：v0.1.0（`825f93d` 基线）。

**本版实现**：

1. **packOptions 忽略 docs/**（`1d56756`）：校对工作 txt 不再入包，主包约 -292KB。
2. **深色模式「墨色宣纸」**（`cb8fcad`）：
   - app.json 开 `darkmode` + `themeLocation`，新增 theme.json（window 双主题）；
   - app.wxss 定义 40 个 page 级语义变量，`prefers-color-scheme: dark` 整体翻转；
   - 15 个页面 wxss 共 431 处硬编码色替换为变量，浅色视觉零变化；
   - 例外保持：红底按钮烫金字、铜钱印章插画、五行彩圆；**divination 3D 页整体钉死浅色**；
   - TabBar：底色/文字走变量继承；图标 SVG 描边色在 data-URI 内，JS（theme + onThemeChange）
     加 `dark` 类切换 8 条提亮图标。
3. **卦象分享卡 + 全站转发**（`3de5a42`）：
   - utils/sharecard.js：2D canvas 宣纸风 5:4 卡（六爻/卦名/全称/一句话白话），固定浅色；
   - 隐藏画布仅 result 与 dianji/detail（屏外定位；divination 页禁用，webgl 同层渲染教训）；
   - result：`from=share` 回放守卫（不落对方历史）+ 起卦行三态标签 + 「分享此卦」按钮；
   - detail：转发落地 `detail?key=` + 朋友圈 query 带 key；
   - 七个内容页轻量 onShareAppMessage（静态知识页加朋友圈）；个人/流程页不定义转发；
   - 标题全文化口径，零占断措辞（审核红线）。
4. **背景音乐预留接口**（`166a804`）：
   - utils/bgm.js：InnerAudioContext 全局单例（loop / obeyMuteSwitch / volume 0.22），
     跨页不断播；app.json 声明 `requiredBackgroundModes:["audio"]`；
   - **预留态**：BGM_SRC 留空 = 未配置，点音符仅提示绝不发声（与 AI_API 同范式）；
   - 「我的」页背景音乐卡 + 音符按钮（唯一出声入口，守微信「禁自动播放」规范）；
   - 开关按播放态驱动，冷启动默认亮但无声。

**验证**：临时导入脚本 39 + 11 断言全过；引擎 22/22；wxss 非 ASCII 选择器 0、
花括号配平、var 引用完整。真机矩阵仍未跑（见 [真机回归清单.md](真机回归清单.md)
第五/六节为本版新增检查项）。

**已知风险**：iOS 真机 InnerAudioContext 后台续播（清单五-4）；深色真机观感未验。

**打版说明**：功能代码基点为 `166a804`；本记录提交紧随其后（仅文档 + 版本号），
git tag `v0.2.0` 落在含本文档的记录提交上，回退即回退到该 tag。

## v0.1.0（基线 · 2026-08-26 及之前 · commit `825f93d`）

**定位**：主链路与内容层全量完成。

- 3D 摇卦闭环（龟壳铜钱/手势拨动）→ 排盘 → 卦成 → 历史（ly_history，id 锚定）；

  内容管线全人工校对闭环，载入断言体系（含京房八宫 64 卦全表推导断言）；
- 知识页：解卦术语速查 / 五行基础 / 八卦基础 / 卦象速查；

- 历史回看直达只读卦成页；一事一占软提示（蒙卦辞）；
- 摇卦音效、问事签、免责声明体系（审核口径全站贯彻）。

细账见开发日志 ①–㊸。

## v0.3.0（计划中 · 未动工 · 本轮讨论已定稿）

**前置**：v0.2.0（其中第 4 项依赖 v0.2.0 铺好的深色变量体系）。

1. **tab 三页纯色固定顶栏**（解卦/典籍库/我的；已定方案 A 纯色不透明 + 底边细金线，
   内容区让位）——修复长内容滚动钻到状态栏/胶囊底下的遮挡乱象。独立，可先行。
2. **卦成页问易按钮分态**（已解读 → 「回看 · 问易解读」直达已存文字；未解读保持原样）。
   独立，改动小。
3. **本变合参解读规格**（仅立档，实施待 AI 后端）：单篇综合解读 = 所问 + 日干支 +
   本卦（宫/六亲/世应/动爻及爻辞）+ 变卦（名/宫/趋势义），四段结构
   「本卦现状 → 动爻之几 → 变卦趋向 → 合参所问」；askAI payload 补带变卦信息。
4. **设置页**（已定：独立设置页）：深色模式三态（跟随系统/浅/深，`.theme-dark`
   类覆盖变量 + storage `ly_theme`，TabBar 联动）+ 阅读正文字号三档（典籍详情/十翼/
   问易正文，`--fs-*` 变量）+ 背景音乐卡迁入。面最大，放最后。

顺序建议：1 → 2 →（3 随文档）→ 4。
