## v0.4.0（当前版本 · 2026-08-27 · tag `v0.4.0`）

**定位**：云端切换轮——云开发部署收官，问易从「本地合成模拟」切到
「豆包（火山方舟）经云函数中转」的真模型解读，v0.3.24 预留的 v0.4.0 到站。
同批修复成卦页模拟器触摸失联（双根因），问易页改进页自动起问。要点：

- **云端上线**：`WENYI_MODE='cloud'`（`WENYI_CLOUD_ENV` 填 cloud1 环境），
  云函数 wenyi 部署 + 环境变量四件配置完成；端↔云↔豆包全链路验证通过
  （控制台测试 payload 与真机进页自动起问均出四段解读）。云端任一失败
  仍自动降级本地合成并标注「本地合成（模拟）」；
- **成卦页触摸失联双根因**：① app.json `lazyCodeLoading` 备份A 误回归
  （7c0c82c 加 → 7f4d1ee 删 → 1ca0c4b 误回 → 本版再删；分包页视图层注入
  的已知怪问题来源）；② 分享画布 dpr 放大后原生层远大于视口诱发同层渲染
  失效挡触摸——改「即用即拆」：导出成败皆置 `cardDone`，wxml `wx:if`
  摘节点，容器改零尺寸裁剪收纳；
- **问易自动起问**：onLoad 末即 `onAsk()`（撤「开始问易」按钮）；已存解读
  只回看不重问（一事一占 + 不重复计费）；失败态（非加载且无解读）留
  「重新生成」唯一入口；
- 成卦页主按钮分态文案「问易 · 合参 / 回看 · 问易」+ 单行限宽；讲解区
  卦辞悬挂缩进（折行对齐「卦辞：」冒号）；
- 踩坑存档：云函数环境变量曾半截入库（`WENYI_BASE_URL` 只剩
  `https://ark.cn-beijing`）→ `getaddrinfo ENOTFOUND` → `MODEL_ERR` →
  端上按设计降级，表象「云端不可用」——**环境变量值必须整段粘贴，以
  「测试」按钮实际返回为准**（配置台值列有显示截断，看不出存没存全）；
  另配置更新窗口期控制台「测试」报 `scf/Invoke ret=-3` 属部署中，等
  状态回正常重试即可。

**result/wenyi 页 wxml/wxss 有动，上传前须开发者工具整编**；mine.js VERSION
0.4.0。验证：132/132（wenyi 84 / liuyao 35 / gua 13）、包全域七禁词 0、
本地直连 2/2（doubao-seed 约 17s/次）。下一版：上线前整备（云函数限流、
AIGC 标识复核、真机回归清单走查）。
