## v0.3.0（当前版本 · 2026-08-26 · tag `v0.3.0`）

**定位**：体验修复轮——用户实测反馈四项（导航遮挡 / 问易回看断链 / 本变合参 / 设置缺失）。

**前置**：v0.2.0（第 4 项依赖其 CSS 变量体系；第 1 项复用其边线/阴影变量）。

**本版实现**：

1. **纯色固定顶栏**：解卦 / 典籍库 / 我的（tab 页）+ 卦详情 / 十翼通读（长正文页，带
   返回键）。`position:fixed` + `var(--bg)` 不透明 + 底边细金线；内容以
   `calc(状态栏px + 88rpx)` 让位（rpx 混算，宽屏精确）；其余长页（排盘/结果/五行/
   八卦/八宫/问易）本就 `scroll-view` 内滚，顶栏不可能被滚上去，不动。
2. **问易按钮分态 + 挂靠修复**：根因在 wenyi.js 只在「无参 + id」时才查历史条目——
   从卦成页**带全参**进问易时 `_entry` 恒空，已存解读从不加载（即用户所见断链）。
   改为「有 id 即挂靠」；result 主按钮已解读 → 「回看 · 问易解读」，onShow 返回即
   刷新；去重合并进旧条目（解读挂旧 id）的情形一并覆盖。
3. **本变合参规格立档** [问易解读规格.md](问易解读规格.md)：四段结构
   「本卦现状 → 动爻之几 → 变卦趋向 → 合参所问」、payload 契约（补 name/bian/
   bianName）、审核口径与不杜撰约束；askAI payload 已按规格带全，实施待 AI 后端。
4. **独立设置页** `pages/settings`（自「我的」进入）：
   - 深色模式三态：跟随系统 / 浅色 / 深（storage `ly_theme`；`.t-light`/`.t-dark`
     覆盖类挂各页根节点，app.wxss 声明全套变量；TabBar 图标 + 消费变量联动，
     `pageLifetimes.show` 返回刷新；**divination 3D 页不挂类保持浅色**）；
   - 阅读正文三档：标准 / 大 / 特大（`--fss` 缩放系数 1 / 1.15 / 1.3，正文写
     `calc(Xrpx * var(--fss,1))` 层级不压扁；作用于卦详情 / 十翼 / 问易正文 +
     设置页预览行；界面其余字号不变）；
   - 背景音乐卡自「我的」迁入（行为不变：预留态无声、手动点音符开启）；
   - 14 页根节点接覆盖类；4 页状态栏 spacer 移入 `.page` 内，消除手动主题顶部接缝。

**验证**：临时脚本 310 断言（theme 三态 / 设置页 / mine / result 分态 / wenyi 挂靠 /
全页冒烟 / wxml 配平 / wxss 扫描）+ 引擎 22/22；真机矩阵仍未跑（清单新增第七节）。

**已知风险**：手动主题下 iOS 过度回弹瞬间可能露出系统色（page 元素背景无法逐页
覆盖，接受）；二级页首帧极端时序理论上可闪一帧（onLoad 内 setData 已合并进首渲染）。

## v0.2.0（2026-08-26 · commit `166a804`）

**定位**：体验层收官轮——P2-9 分享与深色完成 + 背景音乐接口预留。

**前置**：v0.1.0（`825f93d` 基线）。

**本版实现**：

1. **packOptions 忽略 docs/**（`1d56756`）：校对工作 txt 不再入包，主包约 -292KB。
2. **深色模式「墨色宣纸」**（`cb8fcad`）：
   - app.json 开 `darkmode` + `themeLocation`，新增 theme.json（window 双主题）；
   - app.wxss 定义 40 个 page 级语义变量，`prefers-color-scheme: dark` 整体翻转；
   - 15 个页面 wxss 共 431 处硬编码色替换为变量，浅色视觉零变化；
   - 例外保持：红底按钮烫金字、铜钱印章插画、五行彩圆；**divination 3D 页整体钉死浅色**；
   - TabBar：底色/文字走变量继承；图标 SVG 描边色在 data-URI 内，JS（theme + onThemeChange）
     加 `dark` 类切换 8 条提亮图标。
3. **卦象分享卡 + 全站转发**（`3de5a42`）：
   - utils/sharecard.js：2D canvas 宣纸风 5:4 卡（六爻/卦名/全称/一句话白话），固定浅色；
   - 隐藏画布仅 result 与 dianji/detail（屏外定位；divination 页禁用，webgl 同层渲染教训）；
   - result：`from=share` 回放守卫（不落对方历史）+ 起卦行三态标签 + 「分享此卦」按钮；
   - detail：转发落地 `detail?key=` + 朋友圈 query 带 key；
   - 七个内容页轻量 onShareAppMessage（静态知识页加朋友圈）；个人/流程页不定义转发；
   - 标题全文化口径，零占断措辞（审核红线）。
4. **背景音乐预留接口**（`166a804`）：
   - utils/bgm.js：InnerAudioContext 全局单例（loop / obeyMuteSwitch / volume 0.22），
     跨页不断播；app.json 声明 `requiredBackgroundModes:["audio"]`；
   - **预留态**：BGM_SRC 留空 = 未配置，点音符仅提示绝不发声（与 AI_API 同范式）；
   - 「我的」页背景音乐卡 + 音符按钮（唯一出声入口，守微信「禁自动播放」规范）；
   - 开关按播放态驱动，冷启动默认亮但无声。

**验证**：临时导入脚本 39 + 11 断言全过；引擎 22/22；wxss 非 ASCII 选择器 0、
花括号配平、var 引用完整。真机矩阵仍未跑（见 [真机回归清单.md](真机回归清单.md)
第五/六节为本版新增检查项）。

**已知风险**：iOS 真机 InnerAudioContext 后台续播（清单五-4）；深色真机观感未验。

**打版说明**：功能代码基点为 `166a804`；本记录提交紧随其后（仅文档 + 版本号），
git tag `v0.2.0` 落在含本文档的记录提交上，回退即回退到该 tag。
