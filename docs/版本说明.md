## v0.3.3（当前版本 · 2026-08-26 · tag `v0.3.3`）

**定位**：顶栏观感统一轮——用户看图复测（五行/八卦「依旧太高、顶天」，「我的」
标题高度为唯一认可参照；典籍库/解卦报标题顶天 + 底部导航仍遮挡）。

**前置**：v0.3.2。

**取证**：五张截图经视觉模型核对，圆钮直径 ≈35px 对应 64rpx（v0.2.0 尺寸，
v0.3.1 已收至 56rpx）；git 考古 v0.2.0 起 tab 页让位一直是 140rpx——**截图对应
v0.3.1 之前的构建**，v0.3.1/v0.3.2 两轮改版均需开发者工具整编后才见效。取证同时
暴露两处与构建新旧无关的真问题，本版修掉：

1. **二级页顶栏全面对齐「我的」节奏**：9 页（五行/八卦/八宫/排盘/卦成/问易/
   卦详情/设置/十翼）栏体统一 **状态栏 + 88rpx**（与 tab 三页认可高度一致）；
   **实底圆钮换裸箭头**（64rpx 宽、52rpx 细字 ‹、上下 16rpx 点击衬垫、垂直居中
   ——十翼页既有范式推广）。「顶天」根因是实底圆钮上缘距状态栏仅 8rpx 视觉挤死；
   裸箭头居中于 88rpx 栏内，墨迹距顶约 24rpx，与「我的」标题同一空气层。固定
   顶栏两页（卦详情/设置）内联顶距简化为「状态栏 px」、页身让位 72 → 88rpx。
2. **tab 三页底部让位改实体垫块**：解卦/典籍库/我的的 tabbar 让位由 scroll-view
   自带 `padding-bottom: 140rpx` 改为滚动内容尾部 `<view class="tab-clear">`
   （`calc(170rpx + env(safe-area-inset-bottom))`）——scroll-view 底 padding
   在部分机型会截短滚动范围（末条压进 tabbar），实体垫块免疫该怪癖，并补上
   全面屏 Home 条安全区。

**验证**：批量替换 22 处断言全命中；旧标记 grep 清零；12 wxss 花括号配平、
6 wxml 标签配平；`height:88rpx` 全站 12 处恰合预期；mine.js `node --check`；
引擎 22/22。真机矩阵仍未跑。

**已知风险**：裸箭头无实底，深色下对比度依赖 var(--text-2)（与十翼页同源）；
返回键点按热区约 32×42px（原圆钮 28×28px，实际变大）。

**后置**：v0.4.0（AI 后端 / BGM / 真机回归 / 发布准备，计划不变）。

## v0.3.2（2026-08-26 · tag `v0.3.2`）

**定位**：用户实测六项反馈修复轮（导航遮挡根治 / 全站更名 / 成卦字号 / 问易措辞 /
合参呈现补档 / 设置三态提示）。

**前置**：v0.3.1。

**本版实现**：

1. **tab 三页导航遮挡根治**：解卦 / 典籍库 / 我的由「fixed 顶栏 + calc 让位」改为
   **文档流顶栏 + scroll-view 内滚**（与五行 / 八卦 / 排盘等 7 页同范式）——内容
   在滚动容器内滚，物理上不可能钻到顶栏底下；tabbar 让位 140rpx 挪进滚动内容
   底 padding。此前 fixed 方案在用户环境仍报遮挡（代码侧结构与「我的」逐项一致、
   未定位出差异，直接换结构性免疫的范式）。
2. **全站更名 易卜六爻 → 易研六爻**：13 文件——app.json 分享基名、sitemap、
   project.config 描述、README、技术文档 / 优化方向 / 开发日志标题、分享卡落款
   （sharecard.js）、首页大字与分享标题（index）、detail / result 分享标题、
   「我的」关于文案。GitHub 仓库名 `yibu-liuyao` 未动（远端重命名需用户操作）。
3. **成卦页正文字号接入三档**：卦辞 / 彖象 / 白话 / 爻辞 4 条规则接
   `calc(Xrpx * var(--fss,1))`，设置页说明同步加「成卦」。
4. **问易措辞去直白**：卦成页主按钮「问易 · AI 解卦」→「问易 · 合参此卦」；
   问易页卡头→「问易解读」、预告文案与页脚去「AI」字样（审核口径更稳）。
5. **合参呈现方式补档**（[问易解读规格.md](问易解读规格.md) 第六节）：整篇合参
   解读为主体，本 / 变卦经文不在解读内重复——卦成页两框分列 + 典籍详情即
   「整合讲解 + 单独读本卦、变卦」，现有页面已承载。
6. **设置页深色三态提示**：「跟随系统」下加当前系统外观说明（系统为浅色时与
   「浅色」效果相同，差别在系统切深色时显现），sysTheme 注入 onLoad/onShow。

**验证**：三页 wxml view/scroll-view 配平、4 wxss 花括号配平、settings.js
`node --check`、引擎 22/22、改名残留 0。真机矩阵仍未跑。

**已知风险**：卦详情 / 十翼 / 设置三页仍为固定顶栏 + calc 让位（本版未转
scroll-view），若真机仍见遮挡按同法转换；「合参此卦」措辞待用户过目。

**后置**：v0.4.0（AI 后端 / BGM / 真机回归 / 发布准备，计划不变）。

## v0.3.1（2026-08-26 · tag `v0.3.1`）

**定位**：顶栏高度收紧——用户实测反馈二级页标题栏与返回键偏高
（参照系：「我的」页 88rpx 标题栏、摇卦页悬浮返回键「状态栏 + 8px」节奏）。

**前置**：v0.3.0。

**本版实现**：

1. **二级页顶栏统一收矮**：`.topbar` 上下留白 16/8 → 8/8rpx（栏体 88 → 72rpx），
   返回圆钮 64 → 56rpx（字形 48 → 38rpx），标题右让位 64 → 56rpx 跟随（光学居中）。
   覆盖 10 页：五行 / 八卦 / 八宫 / 排盘 / 卦成 / 问易 / 卦详情 / 设置 / 十翼；
   固定顶栏三页（卦详情 / 设置 / 十翼）的 wxml 让位 calc 同步 88 → 72rpx。
   tab 三页（解卦 / 典籍库 / 我的）88rpx 纯标题栏为用户认可高度，不动。
2. **问事页返回键对齐摇卦页节奏**：顶距 `env(safe-area-inset-top) + 16rpx` →
   内联 `calc(状态栏px + 8rpx)`（env() 部分真机失效，改走 JS px 值，与摇卦页
   cover-view 同法；ask.js 补 `statusBarHeight` 注入），圆钮同步 56rpx。

**验证**：grep 残留清零（旧 padding / 64rpx 顶栏圆钮无存留，88rpx 仅存 tab 三页
标题栏）；ask.js `node --check` 过；纯样式改动，引擎与数据未动。真机矩阵仍未跑。

**已知风险**：返回键触达面积缩小约 12%（56rpx ≈ 28px@375，仍在自定义返回键
常规范围），真机点按手感待回归确认（清单 §七-9）。

**后置**：v0.4.0（AI 后端 / BGM / 真机回归 / 发布准备，计划不变）。

## v0.3.0（2026-08-26 · tag `v0.3.0`）

**定位**：体验修复轮——用户实测反馈四项（导航遮挡 / 问易回看断链 / 本变合参 / 设置缺失）。

**前置**：v0.2.0（第 4 项依赖其 CSS 变量体系；第 1 项复用其边线/阴影变量）。

**本版实现**：

1. **纯色固定顶栏**：解卦 / 典籍库 / 我的（tab 页）+ 卦详情 / 十翼通读（长正文页，带
   返回键）。`position:fixed` + `var(--bg)` 不透明 + 底边细金线；内容以
   `calc(状态栏px + 88rpx)` 让位（rpx 混算，宽屏精确）；其余长页（排盘/结果/五行/
   八卦/八宫/问易）本就 `scroll-view` 内滚，顶栏不可能被滚上去，不动。
2. **问易按钮分态 + 挂靠修复**：根因在 wenyi.js 只在「无参 + id」时才查历史条目——
   从卦成页**带全参**进问易时 `_entry` 恒空，已存解读从不加载（即用户所见断链）。
   改为「有 id 即挂靠」；result 主按钮已解读 → 「回看 · 问易解读」，onShow 返回即
   刷新；去重合并进旧条目（解读挂旧 id）的情形一并覆盖。
3. **本变合参规格立档** [问易解读规格.md](问易解读规格.md)：四段结构
   「本卦现状 → 动爻之几 → 变卦趋向 → 合参所问」、payload 契约（补 name/bian/
   bianName）、审核口径与不杜撰约束；askAI payload 已按规格带全，实施待 AI 后端。
4. **独立设置页** `pages/settings`（自「我的」进入）：
   - 深色模式三态：跟随系统 / 浅色 / 深（storage `ly_theme`；`.t-light`/`.t-dark`
     覆盖类挂各页根节点，app.wxss 声明全套变量；TabBar 图标 + 消费变量联动，
     `pageLifetimes.show` 返回刷新；**divination 3D 页不挂类保持浅色**）；
   - 阅读正文三档：标准 / 大 / 特大（`--fss` 缩放系数 1 / 1.15 / 1.3，正文写
     `calc(Xrpx * var(--fss,1))` 层级不压扁；作用于卦详情 / 十翼 / 问易正文 +
     设置页预览行；界面其余字号不变）；
   - 背景音乐卡自「我的」迁入（行为不变：预留态无声、手动点音符开启）；
   - 14 页根节点接覆盖类；4 页状态栏 spacer 移入 `.page` 内，消除手动主题顶部接缝。

**验证**：临时脚本 310 断言（theme 三态 / 设置页 / mine / result 分态 / wenyi 挂靠 /
全页冒烟 / wxml 配平 / wxss 扫描）+ 引擎 22/22；真机矩阵仍未跑（清单新增第七节）。

**已知风险**：手动主题下 iOS 过度回弹瞬间可能露出系统色（page 元素背景无法逐页
覆盖，接受）；二级页首帧极端时序理论上可闪一帧（onLoad 内 setData 已合并进首渲染）。
