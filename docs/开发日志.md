### ⑤ 真机预览超 2MB：体积诊断与结构调整（同日续）

**现象**：真机预览报代码超限——`package3d` 2229KB > 2048KB 限额（工具编译不查，真机预览才拦）。

**诊断过程（三连排除，最终找到真凶）**：

1. **贴图不是问题**：解析 glb JSON 块发现贴图极小——shell 内嵌 3 张 webp 共 56KB、coin 一张 PNG 11KB。
   早前"Blender 重导压贴图"的判断被推翻；
2. **面数不是问题**：龟壳 2.4 万面、铜钱 6.5 千面，都是低模。体积大头是 **float32 顶点属性**（32B/顶点）；
3. **引擎挡住了正规解**：顶点量化（`KHR_mesh_quantization`）实测 shell -29%、coin -34%，能过限——
   但 grep 发现内置引擎是 **three r108**，该扩展 r121 才支持，量化模型会加载失败；
   `weld`/`prune` 实测几乎零收益（模型导出时已优化）；`simplify` 减面被 error 容差拦住（铜钱只减了 6 个面）。

**解法**：结构平衡——`coin.glb` 移主包 `models/`、`shell.glb` 留分包。主包 841KB ✓ / 分包 1585KB ✓，
零画质损失零兼容风险。原模型备份 `tools/reference/models-orig/`。

**教训**：

- "包超限"先**解析 glb 结构**再下结论（JSON 块 20 行代码就能看清贴图/面数/属性），别按直觉上来压贴图；
- 升级依赖前 grep 一下 bundled 库的 `REVISION` 与扩展名，能力边界以实测为准；
- 工具编译不查包体积，**每个版本至少真机预览一次**再算"过"。

### ⑨ 手势拨动龟壳 360°（快照后新增）

**需求**：手指拖动龟壳绕自身中心点 360° 旋转查看，**位置不变**。

**实现**（避开 Euler 顺序坑，不碰壳自身姿态）：

1. **转轴分层**：`THREE.Group`（pivot）固定在壳中心，壳挂为子对象并归零自身 position。
   拖动只改 `pivot.rotation.y`——壳绕中心转、位置天然不变；壳的立起/翻正/后仰/摇晃摆动
   全保留在子对象上，两套动画互不干扰（摇晃仍写 `shell.rotation.z`，基准值不变）。
2. **手势**（wxml canvas 上绑 touchstart/move/end/cancel 四个事件）：
   - move 里 `dx × SPIN_SENS(0.012rad/px)` 累加 `_shellYaw` 跟手；约拖一屏宽转一圈多；
   - 惯性：按 move 事件真实间隔估算角速度作松手初速（限幅 ±8rad/s），松手后
     `yaw += vel·dt`、`vel ×= e^(−SPIN_DAMP·dt)` 指数衰减；按住即清零惯性；
   - 多指防护：记录首个触点 `identifier`，move 只认它，全部手指离开才结束拖动。
3. **渲染循环**：update() 顶部（`if (!_shaking) return` **之前**）统一写
   `pivot.rotation.y = _shellYaw`——铜钱物理、读面判定、跳转全不受影响。

**验证**：`node --check` 通过；引擎测试 22/22。真机待验：拖动手感（SPIN_SENS/SPIN_DAMP 可调）、
拖动与摇卦按钮/摇一摇是否有误触。

**回退**：删 wxml canvas 四个 bind、js 三个 onShellTouch* 与 update() 顶部拨动块、
init() 的 pivot 包装（恢复 `scene.add(shell)`），常量区删 SPIN_SENS/SPIN_DAMP——
壳即回到 ⑧ 快照姿态。

### ⑪ 松手弹簧回位（同日续）

**需求**：不管转到什么角度，松手后 2~3s 内自动回正到初始姿态（正面朝镜头、竖直）。

**实现**：自由惯性（指数衰减）替换为**欠阻尼弹簧**（半隐式欧拉积分）：
`acc = −SPRING_K·(角−目标) − SPRING_C·角速`。K=5（回正≈2.2s）、C=4.2（临界≈4.47，
略欠阻尼几乎不过冲）。关键细节：

- **速度连续**：弹簧以松手时的角速度为初速——甩出去的势头先顺势衰减、再被拉回，
  无「急刹车」跳变；
- **yaw 目标取最近整圈**（`round(yaw/2π)·2π`）：转过三圈半也只倒转半圈回正面，最短路径；
- pitch 目标恒为 0（回竖直），回位途中仍受 ±85° 夹紧；
- 到位阈值（角差<0.002 且 |v|<0.02）吸附归零、`_homing=false`；拖动开始即取消回位。

常量 `SPIN_DAMP` 删除（不再用指数衰减），新增 `SPRING_K`/`SPRING_C`。
回退 = update() 拨动块换回 ⑩ 的惯性版、常量对调。

### ⑬ 摇卦仪式闭环：问事签 → 装钱 → 摇动 → 倒出（2026-08-25 续）

**流程**：点起卦 → 问事签弹卡（所问何事，可不填，随 `q=` 传排盘落历史）→ 壳后仰成碗
（`LOAD_ANGLE=1.5`）→ 拖三钱入壳（射线拾取 + 桌面平面拖动，落点距壳心 ≤`LOAD_RADIUS`
算入）→ 3/3 壳立正 → 提示摇手机（有效晃动 ×`SHAKE_HITS`=4，静默 `SHAKE_QUIET`=800ms
判定停止）→ 壳前倾（`POUR_ANGLE=−1.9`）过 55% 从壳口松钱 → 自由落体到桌面 → 读面成爻 →
回正回观赏态。六爻循环 6 次成卦跳排盘。

**关键机制**：

- **壳姿态统一为「目标角趋近」**：`tilt += (target−tilt)·min(1, dt·TILT_SPEED)` 指数趋近
  +到位一次性回调，装钱/立正/倒出/回正共用；替代 B 阶段的 pourT 进度条方案
- **状态机** idle/loading/righting/shaking/pouring/settling/returning；弹簧回位与手势拨壳
  仅 idle 生效，仪式各阶段壳由流程接管
- **射线交互**：Raycaster + NDC（触摸 px → 归一化），拖钱沿 `y=FLOOR_Y+0.3` 平面
  （`Plane.intersectPlane`），命中子网格沿父链找所属铜钱，loaded 标记防重复拖
- **兜底**：摇动阶段点按钮 = 补一次有效晃动（工具模拟不了加速度计）；问事签可不填

**踩坑**：A 阶段 `onQiuConfirm` 曾调用后被删除的 `startDrop`（语法查不出，运行才爆）——
大规模改流程后要 grep 旧入口。另：Edit 工具 old_string 与文件差一个空行即失败，
改大块前先 Read 精确文本。

**再踩（同日）**：C 阶段按钮文案加到四层嵌套三元后 WXML 编译报
`error at token ')'`——wxml 表达式解析器深嵌套不可靠。**修法**：文案全部收进 JS
`updateBtn(patch)` 集中计算（patch 里带最新 phase/lines/done，优先取新值），
各状态转换点 `updateBtn({...})` 一并 setData，wxml 只读 `{{btnLabel}}`。
顺带收益：文案逻辑集中一处，比散在模板里好维护。

**流程精化（同日二续）**：① 进页模型就绪即自动弹问事签，按钮退出入口职责，
仪式阶段（装钱/立正/倒钱/落定/回正）隐藏；② 拖钱靠近壳口（x/z 距 < `LOAD_RADIUS`
=1.15）**自动聚拢入壳**，不必精确松手；③ 摇动时壳 yaw 摆动 ±0.3rad·amp（叠加原有
z 轴晃动），点画布任意处=补一次晃动；④ 音效待配（摇壳声/铜钱落桌声）。

**「铜钱没反应」三层洋葱（同日三续，重点）**：一层=3D 初始化偶发失败时画布空、
清屏色与页面底色相同看不出失败（修：报错带真实 errMsg + 按钮「重新加载」整页
redirect + onUnload 补 `renderer.dispose/forceContextLoss` 防 GL 上下文耗尽）；
二层=用户在待机态直接摸钱（修：待机触钱=起卦）；三层=**首帧渲染前 `matrixWorld`
是 clone 带来的旧值，raycast 全 miss**（修：pickCoin 前 `scene.updateMatrixWorld()`）。
教训：射线拾取前永远先刷新矩阵；探测代码要在真实时机跑，太早跑出假阴性。

**四层（终局，同日四续）**：矩阵刷新后 `intersectObjects` 对铜钱/壳**依然恒 miss**
（射线向与理论值完全一致、直穿包围球球心仍 0 命中）——判定 threejs-miniprogram
构建的 mesh 求交不可用。**弃用 raycast，改纯数学**：拾取=投影钱心到屏幕算距离
（热区 `PICK_PX`=55px，手指友好）；拖动=像素增量 × `2·tan(fov/2)·dist/winH`
世界/像素比。投影链路（`project()`）经实测可靠。教训：**小程序 scoped three
别假设 raycast 可用，交互用投影+平面数学更稳**；另热重载保留页面实例状态，
`_asked` 存活导致「进页自动弹问事签」在热重载后不弹（全新进入正常）。

**验证**：`node --check` + 引擎 22/22；**真机待验**：拖钱拾取手感、LOAD_RADIUS 松紧、
倒出落点、摇一摇节奏、BACK_PARITY 标定。

### ⑭ 问事签弹卡终局：拆独立页（2026-08-25 续，重点）

**现象**：问事签弹卡首进必不显示（直接见龟壳场景），点工具「刷新/编译」后正常。
历轮排查依次排除：幽灵确认（删 `bindconfirm`）、弹得过早被导航残留点击关掉
（推迟到场景就绪 +300ms）、热重载实例状态（`_asked` 存活）。**定性证据**：
加了逐秒状态记录器后，日志连续 5 秒 `asking=true phase=idle` 且无任何
「确认/跳过/忽略过快确认」——**数据是弹开着的，用户看不见**。

**根因**：同层渲染偶发失效（日志⑦同源）：`type="webgl"` 画布首进时未挂进
WebView 层级，原生画布层浮在所有 view 之上；画布清屏色不透明，把弹卡、按钮、
提示全盖住。刷新后同层挂接成功才恢复。弹卡与画布同页无解（时序怎么调都赌运气）。

**修法（结构性）**：问事签拆独立页 `package3d/pages/ask`（纯 WebView 页，无画布，
必然显示）。新流程：首页「摇卦起卦」→ 问事签页（输入所求）→ `redirectTo`
3D 页（`?q=` 带所求）→ 场景就绪即自动 `beginLoad()` 装钱，不再依赖画布上的弹层。
卦成后「重新起卦」也回问事签页（redirect，先清 `_navTimer` 防双跳）。所求
`q` 参数 → `_qiu` → 排盘页 → 历史，链路不变。同步清理：3D 页弹卡代码/样式、
`selfTestPick`（拾取 3/3 已两轮验证）、逐秒状态记录器；保留 `[装钱] 拾取` 一条
日志待拖钱手感稳定后删。防幽灵确认闸移到问事签页（onReady 后 600ms 才收按钮）。

### ⑯ 铜钱姿态实证：模型默认立着，判面直读法线（2026-08-25 续，重点）

倒出的钱屡次「立着收场」，两轮 Euler 压平（snap 到 π 整数倍）都无效——**不再猜，
写脚本解析 coin.glb 几何**（读 GLB JSON chunk 的 accessor min/max）：钱体圆盘厚
0.033 沿 local Z（宽 0.67/0.66）⇒ **法线沿 Z，单位旋转就是立着的**（placeCoinsIdle
的 (0,γ,0) 一直是立钱，此前没人发现）；「乾隆通宝」汉字贴 +Z、满文贴 −Z。
据此重构：平躺 = Euler(∓π/2,0,γ)（待机摆钱字面朝上）；落定压平改 **quaternion.slerp
到就近翻倒面**（法线 y 符号定倒向，正反面仍由翻滚物理决定）；**判面 isBackUp 改读
盘面法线世界方向（n.y<0 = 字面朝下 = 背面朝上），BACK_PARITY 奇偶标定项整个删除**。
教训：**模型朝向问题一步到位的办法是解析 glb 读几何，别靠渲染截图反推**；
Euler 三个角对「平躺」这种约束不封闭（y 自转会破坏法线竖直），姿态动画用四元数。

**教训**：原生组件（canvas/video/map）页面上的关键交互浮层是赌同层渲染的运气；
**关键决策入口要么独立成页，要么用 cover-view**。诊断「看不见」类问题时，
状态记录器（定时打 data 快照）能一步分清「数据没到」vs「数据到了没渲染」。

### ⑰ 落定判定修复 + 六爻自动循环（2026-08-25 续）

上一轮压平动画引入双 bug 同根：物理循环跳过条件写成 `settled && !flat`，

随后闭环成型：**读面监测日志**（`[读面] 背·字·背 → 两背一字，少阴`——面是落定后

### ⑱ 刻爻上壳仪式（2026-08-25 续，重点）

自动续摇一轮即被否：**钱停桌面时间太短看不清，且用户要手动拖回**——续爻改回
装钱态等拖拽（复用整体拖钱机制，零新增交互代码）。腾出的节拍给了新仪式：
**每得一爻，壳转背面 → 爻线「刻」上腹甲 → 停留赏看 → 转回正面**（暗合龟甲刻辞）。
实现要点：①刻线挂 `_marksGroup`（shell 子对象），随壳转/翻，平时拨壳也能翻看；
②**贴背定位靠运行时包围盒**——`Box3.setFromObject(shell)` 必须在 fitObject 后、
SHELL_ADJUST 姿态前取（此时矩阵=模型局部系），腹甲面=局部 min.Y、
局部 +Z→世界竖直 ⇒ 初爻刻 -Z 端，爻线长度/行距按包围盒自适应；
③刻线=BoxGeometry 浮雕（半嵌入 min.Y 面），阳一整条/阴两段、动爻朱红，
从中点向两侧生长（scale.x 0→1）模拟刻凿；④仪式=update 内四段式时间线
（turn→carve→hold→back，ease01 插值），**直接接管 _shellYaw/_shellPitch**
（手势在此阶段已被 phase 守卫禁用，无争抢）；转回目标=最近正面整圈。
⑤卦成：tip 亮卦名（主包 GUA_DATA，分包可引），**跳排盘挪到仪式收尾**——
删 _navTimer 定时器，防仪式被跳转打断。

**首测翻车与修正（刻线全部悬空）**：包围盒取的是 fitObject **之后**的世界系
数值，而刻线挂在 shell 子节点、吃的是**模型原生局部系**——差一个缩放系数
（≈3.1 倍）加平移，六条线整体飞出壳外。且整体盒 min.Y 是「最凸一点」，
腿/裙边会把刻字面拉低。修正：世界盒换算回局部系（减 position 除 scale）；
**backY 改在刻字中央带（|x|≤25%、|z|≤45%）内逐顶点探测最低面**——凸出物在
带外拉不高刻字面，刻线贴的是腹甲真实表面。教训：**给模型挂子物件，
定位必须用「除掉自身矩阵」的局部系；求贴合面别信整体包围盒，限定区域内
探顶点**（本环境 Raycaster 不可用，顶点遍历是唯一的几何探测手段）。
刻线尺寸/行距/嵌深全改为对包围盒的**比例值**（换模型免调绝对数）。

### ⑳ 拆段方块被判「更丑」→ 毛笔笔道纯几何刻痕（2026-08-25 续）

⑲ 的「小段方块拼裂痕」真机读感是**粗块堆积**——几何方块这条路到头了：随机段
叠出来要么像直棒、要么像碎石，中间态不存在。先试「整行画到离屏画布再贴图」，

absarc 封口=圆头），上下缘各成一排轮廓点拼成平面 Shape——零厚度、天生贴面、
无体积凸出，正是「毛笔画上去」。几何 `rotateX(π/2)` 烘焙平躺（法线 −Y 朝壳外），
mesh 的 rotation.y 留给面内摆角（老阴 ✕ 两臂 ±45°，错层 0.012·gap 防相交闪面；
老阳 ○ = 圆环 Shape 带孔，错层防与穿线 z-fighting）。**卦名**仍走 CanvasTexture
（文字没法用几何画）：WXML 藏一张 `type=2d` 画布节点（`position:fixed;
left:-2000px`，display:none 会画不上），init 时 SelectorQuery 取 node 存
`_inkNode`，跨局复用需先 clearRect；画布取 2 的幂 512×128（WebGL1 NPOT 贴图
不能建 mipmap）。刻出动画保留 scale.x 从中点向两侧长出。
**穿模修正（同日再续）**：整带一个 backY 垫平六行 → 行在弧顶沉进壳里。改为
measureShellBack 顺手收集刻字带顶点 `_backPts`，`probeRow(zc)` 按行探测：

老阳○/老阴✕ 缩小约三分之一（环径 0.20·gap，✕ 臂 0.34·gap）。

### ㉝ WXSS 中文类选择器编译错误修复（2026-08-26 续）

引擎 22/22。教训入库：**wxss 类名一律 ASCII，中文只进内容**。
