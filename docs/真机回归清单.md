## 一、process.mp3 循环接缝（摇动过程音）

**代码事实**：`divination.js:904-906` 单实例 `_loopSfx`，`loop=true`、音量 0.7；
手停 450ms 即停（`divination.js:466-469`，比倒出判定早）；`get_into/dump_out` 各预热
3 实例（`divination.js:899-900`）。

**步骤**：进入摇卦 → 装钱 → 持续摇 10 秒以上（听循环点）→ 停手 → 倒出 → 再来一局。

| # | 检查点 | 判定标准 |
| --- | --- | --- |
| 1 | 循环点接缝 | 摇动 10s+，循环处无明显「咔哒」/骤停感。mp3 编码首尾静音会造成接缝 |
| 2 | 停手即停 | 手停约半秒内过程音止净，无拖尾、无「停了还在响」 |
| 3 | 短音不破音 | 三钱入壳 / 倒出短音连贯，快速连摇时不出现哑音（预热 3 实例够不够） |
| 4 | 切后台/锁屏 | 摇动中切后台再回，声音状态正常（不停播也不重复叠播） |
| 5 | iOS vs 安卓 | 两端音量一致性、接缝表现是否不同 |

**接缝若明显的修复预案**（按成本从低到高）：
1. 重导出 process.mp3：剪首尾静音、尾部 10–20ms 淡出包接缝（零代码改动，先试）；
2. 改双实例交叠：两个 context 相位错开轮播，代码约 20 行；
3. 改命中驱动短音：摇动撞击时播短音替代循环（`_lastHitAt` 事件已有）。

## 二、爻线雕刻与卦名外观

**代码事实**：卦名走 `wx.createOffscreenCanvas({type:'2d'})` 真离屏画布
（`divination.js:167-172`，失败则静默跳过不刻，不崩流程）；`carveGuaName()`
（`divination.js:796`）512×128 画布、`bold 96px sans-serif`、CanvasTexture 贴壳背
上爻上方。**本次已修**：八纯卦刻名原为「天天乾」式，已改「乾为天」式
（与典籍库列表同规则），真机需首次实际确认。

| # | 检查点 | 判定标准 |
| --- | --- | --- |
| 1 | 卦名出现 | 六摇成卦后卦名如约刻出（低端安卓重点：offscreenCanvas 失败会静默不刻，看 vConsole 有无「离屏画布创建失败」） |
| 2 | 八纯卦刻名 | 摇出乾/坤等八纯卦，刻名为「乾为天」而非「天天乾」（本次修复项） |
| 3 | 字体外观 | `sans-serif` 在两端字重宽度不同（iOS 苹方 / 安卓各厂默认），卦名不溢出、不压上爻线 |
| 4 | 清晰度 | 卦名与爻线纹理清晰，无糊化/锯齿刺眼（贴图 512×128，缩放 0.02） |
| 5 | 贴面贴合 | 卦名平面顺弧面倾斜，不同屏宽下不穿壳面、不悬空 |
| 6 | 亮名时机 | 卦成重震一下后卦名亮起（`divination.js:575`），时序不抢戏 |
| 7 | 连续多局 | 第二局起卦名/爻线无残留（画布跨局复用有 clearRect，实测确认） |

**若低端机不刻卦名**：降级方案为 WXML 藏 type=2d 节点方案（已知会诱发同层渲染
失效，见 `divination.js:163` 注释）——不采用；可改为卦成时页面上层 toast 式
卦名横幅兜底。

## 三、WebP→PNG 贴图（龟壳模型）

**代码事实**：`package3d/models/shell.glb`（899KB，分包）内嵌 **3 张 WebP 共 56KB**；
coin.glb 为 PNG（11KB，主包 `models/`）。旧基础库/部分安卓解码链对 GLB 内 WebP
支持不稳，风险是**壳贴图丢失**（纯色/黑壳/纹路缺失）。此前诊断过贴图体积很小，
即使全转 PNG 也只增约 100–200KB，可行。

| # | 检查点 | 判定标准 |
| --- | --- | --- |
| 1 | 壳外观 | 与开发者工具对照：纹路、色泽、细节齐全，无纯色块/丢失 |
| 2 | 低端安卓 | 重点机型上同样正常（WebP 解码失败多在此暴露） |
| 3 | 加载时长 | 冷启动进摇卦页可接受（壳 899KB + coin 11KB，分包按需拉） |
| 4 | 内存 | 连续 3 局无贴图异常（CanvasTexture 有 dispose，`divination.js:853`） |

**若贴图丢失**：gltf-transform（或 Blender 重导）将壳内 WebP 转 PNG 重打包，
`tools/reference/models-orig/` 有原模型备份；转完体积复核（分包红线 2MB，现
1585KB，余量够）。
