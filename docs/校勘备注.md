## 一、遯 / 遁（天山遯卦，key `001111`）—— 2026-08-27 立约定

**现状约定（不擅改底本，两存处理）：**

1. **经传正文文本（卦辞、彖、小象、序卦）：严格保留古籍原文「遯」，不改为遁。**
   例：遯卦，遯之时义大矣哉，天下有山遯；序卦「遯者退也」，全部维持「遯」。
   （tools/reference/zhouyi.txt 与 data/shiyi.js 的原文层即依此。）
2. **程序引擎、索引、查询、数据表卦名字段：使用「遁」。**
   - 用户检索输入「遁」可以命中本卦；
   - 内部主键、下拉选择、64 卦枚举数组用「遁」，适配业务逻辑；
   - UI 展示上做映射兼容：搜索「遯」同样可跳转到此卦
     （`pages/dianji/dianji.js` onSearch 关键词归一化 `遯→遁`，双写皆命中）。

**校勘脚注（小程序知识库内，卦详情页仅此卦显示）：**

> 校勘备注：卦名，古经本作「遯」，后世多通作「遁」。二字为古今异体通写。
> 经传原文依从阮刻刊本作**遯**；程序索引、枚举采用后世通行写法**遁**，双向检索兼容。

**波及面备忘**：utils/liuyao.js `GUA_NAME` 矩阵、data/gua.js name 字段、
data/baihua*.js 锚点 n 字段作「遁」；经传原文层（zhouyi.txt、shiyi.js、

## 二、原文原汁原味原则（含繁体/异体字处理）—— 2026-08-27 立约定

古籍原文**保持原汁原味**：不改字、不简化、不以今律古，一切存真于所据底本。
其中的繁体/异体字（含「遯」及引文原字）**允许出现、原字保留**，不强制转换为
简体；机器工具（tools/qa-baihua-shiyi.mjs 等）对繁体**只标注、不判错**。
展示层沿用既有体例：生僻字随文括注拼音（utils/pinyin.js annotate），
白话译层（「译｜」行）用简体现代汉语，与原文层分离。

## 三、文言/序卦三处字级异文裁定 —— 2026-08-27 终审闭环

双源交叉核对（tools/check-shiyi-vs-zhouyi.mjs：shiyi.js vs zhouyi.txt）曾报
3 处异文，终审**均维持 shiyi.js 读法**。底本：阮元校刻《十三经注疏·周易正义》
（ctext 武英殿本系统），参校朱熹《周易本义》、黄寿祺《周易译注》、中华书局
点校《周易正义》。详见 docs/待人工核对.txt（存档）。

1. **文言·乾九三「君子进德修业」**——zhouyi.txt「进德修业也」系涉下句句末
   「也」字衍误（传抄重文）；
2. **序卦下「伤于外者，必反其家」**——「反于家」为后世传抄讹变；孔颖达疏：
   「既伤於外，必来反其家」；
3. **序卦下「决必有所遇」**——「决必有遇」脱「所」字；孔颖达疏同作「決必有
   所遇」，且合序卦通篇「必有所……」辞例。

zhouyi.txt 三处转录误已同日订正，交叉核对工具复跑**五篇全部字级一致**。
